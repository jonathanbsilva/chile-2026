# Chile 2026

Hub estático para a viagem ao Chile, de 08 a 16 de agosto de 2026.

## Rodar localmente

```bash
python3 -m http.server 8000
```

Abra `http://localhost:8000`.

## Acesso casual

A senha visual é `chile2026`. Ela não oferece proteção real: o código é público no repositório e a página é hospedada no GitHub Pages. Não coloque neste projeto códigos de reserva, documentos, contatos privados, cartões ou comprovantes.

## Verificação

```bash
node verify.mjs
```

A publicação é feita pela workflow em `.github/workflows/pages.yml` após um push para `main`.
